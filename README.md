# SECRET AGENT GF

A personalized, client-side romantic spy adventure for Lakshita and Prashank, built with React and Vite.

## Run locally

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173/`). For a production build:

```powershell
npm run build
npm run preview
```

## Personalize

Use **About Her → Edit this case file** to change names, her note, and the memory-mission questions, accepted answers, and hints. The letter, future prompts, garden, calendar, collected clues, mission progress, and opened gifts save in this browser.

The photo archive starts with the images in `public/photos/`. You can add local photos and video clips from Memories, and local audio files from Music. Browser-selected media is kept for the current session; it is not uploaded to a server.
